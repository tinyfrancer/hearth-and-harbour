# Hearth & Harbour

A single-player fantasy idle RPG for the phone: train skills from the menus, walk a small town,
fill a house with trophies, and run short action dungeons.

```bash
npm install
npm run dev      # http://localhost:5173
npm run check    # lint, format, typecheck, test, build
```

Installable to the home screen (PWA) and playable offline. Saves live on the device; the Menu tab
exports and imports them as a file or a code.

See `CLAUDE.md` for how the code is laid out and `docs/style-guide.md` for the art direction.
